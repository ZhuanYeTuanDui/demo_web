# 生产功能总结

## 材料范围

本总结依据本目录 `1.png`、`2.png`。目录名称为 `product`，截图实际内容是生产计划与生产入库。结论区分页面直接展示的信息、侧栏菜单入口以及后续开发建议。

## 一句话概括

生产计划可以从订单选择产品并提供展料入口；生产入库可以关联工单，在同一张单据中记录成品入库及对应子件耗用，把生产与库存连接起来。

## 生产计划

### 单据头信息

可见单号、日期、经办人、性质、审核人、部门、公司、结束标识、备注、制单人。

### 取单与展料

1. 新建生产计划后，可通过“取单”打开订单选择窗口。
2. 按订单号、订单日期、品号、预交货日期等条件查询，勾选所需产品。
3. 页面提供“展料”入口，并将主件与子件分区显示。

截图停留在选择窗口，尚未展示确认取单后的计划明细及展料结果。因此只能确认入口和界面结构，不能确认 BOM 展开层级、用量计算和后续工单生成方式。

## 生产入库

### 单据头信息

可见单号、日期、性质、来源、经办人、审核人、部门、备注、制单人、凭证状态。示例显示“审核”，但凭证状态为“未生成”，说明界面将单据审核与凭证生成分别表示，不能把审核等同于财务凭证已生成。

### 主件入库表

可见来源、来源单号、主件品号、品名、规格、单位、入库仓库及名称、批号、批号说明、生产日期等字段。

### 子件耗用表

可见来源、来源单号、序号、子件品号、子件品名、规格、单位、耗用仓库及名称、耗用量、报废耗用量、批号和批号说明。

示例为：一个成品进入成品仓库，对应四个子件从现场仓记录耗用，每个子件耗用量为 1，报废耗用量为 0。该例只说明当前单据的呈现方式，不能推广为所有产品的固定耗用关系。

## 菜单可见但未展开验证的范围

侧栏可见产品结构、生产计划、工单及变更、重工、工单发料、完工入库、委外管理、管理报表，以及生产计划/工单/委外单树状查询入口。

这些入口可作为后续梳理清单，但本目录两张截图不足以确认工单排程、委外结算、生产报工、领料扣账及返工流程。

## 跨模块关联

```text
订单 → 生产计划 → 展料
                    ↓
          物料需求、工单等后续环节（具体衔接待确认）

工单 → 生产入库单 → 成品入库 + 子件耗用记录
```

生产入库与子件耗用在页面中共同出现，但“是否在审核时自动扣减子件库存”仍需确认，不能仅凭界面认定已实现自动倒冲。

## Web ERP 功能划分建议

| 建议入口 | 包含内容 |
| --- | --- |
| 计划与生产 → 生产计划 | 订单取单、主件计划、BOM 展开、子件需求和结束状态；明细查询放在同一入口。 |
| 计划与生产 → 工单 | 工单、变更和关联单据，保留原始计划与订单来源。 |
| 计划与生产 → 完工入库 | 成品入库、子件耗用及报废耗用，按来源工单查询和追溯。 |
| 计划与生产 → 生产追踪 | 通过关联视图查看订单、计划、工单、物料和入库，避免为每一种明细再建一级目录。 |

以上为重构建议，非已确认的现有完整功能。

## 待确认事项

- 计划与 BOM 的版本关系，是否支持多层展开、替代料、损耗率及用量取整。
- 订单如何拆分或合并成计划，计划如何生成工单，变更后如何同步。
- 同一工单是否支持分批入库，如何控制超产、欠产及结束状态。
- 子件耗用是否由工单带入、是否允许修改、是否属于自动倒冲；如何避免与领料单重复扣减。
- 现场仓和成品仓的库存更新时点，审核撤销、入库退回和返工如何处理。
- 报废耗用量是否影响成本，凭证如何生成，批号如何关联到子件与成品。
