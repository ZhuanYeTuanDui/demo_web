# WSN ERP 纯前端演示

基于已有模板的 Vue 3、TypeScript、Element Plus 和 Vite，提供库存、采购、生产三个模块。无需登录、后端、数据库或接口服务，浏览器直接加载 mock 数据。

## 启动

需要 Node.js ≥ 20.19，使用模板锁定的 **pnpm 9.15.3**。保留原有依赖锁文件，没有新增依赖。

```bash
cd D:/projects/WSN/web
pnpm install --frozen-lockfile
pnpm dev
```

打开 http://127.0.0.1:5173/ 。如本机 pnpm 版本不同，可用 `pnpm dlx pnpm@9.15.3 install --frozen-lockfile` 安装、`pnpm dlx pnpm@9.15.3 dev` 启动。

```bash
pnpm type-check
pnpm test:demo
pnpm build
pnpm preview
```

构建输出为 `dist/`，可部署至普通静态文件服务器，预览地址为 http://127.0.0.1:4173/ 。不支持通过 `file://` 双击 HTML 运行。

## 部署到 GitHub Pages

仓库根目录的 `.github/workflows/pages.yml` 会在推送到 `master` 或 `main` 时自动安装锁定依赖、运行演示测试、检查类型并构建，将 `web/dist/` 发布至 GitHub Pages；也支持在 Actions 页面手动运行。

1. 将整个仓库上传到 GitHub，保留根目录 `.github/` 和 `web/` 的位置。
2. 打开仓库 **Settings → Pages → Build and deployment**，将 **Source** 设为 **GitHub Actions**。
3. 推送代码，或在 **Actions → 部署 GitHub Pages → Run workflow** 手动触发。
4. 等待部署成功，通过部署记录中的网址访问，通常为 `https://<用户名>.github.io/<仓库名>/`。

当前配置使用相对资源路径和 hash 导航，支持仓库子路径。无需提交 `dist/`，也无需配置后端环境变量。数据仅保存在访问者自己的浏览器中，不会跨用户或设备共享。

免费账户可使用公开仓库部署；私有仓库使用 Pages 需要支持的 GitHub 付费方案。仓库内 `web/.github/workflows/ci.yml` 是保留的模板配置，GitHub 不会从该嵌套目录加载工作流。

## 已实现页面

| 模块 | 页面及功能                                                                                                                     |
| ---- | ------------------------------------------------------------------------------------------------------------------------------ |
| 库存 | 库存记录：分仓查询、搜索、分页、CSV 导出；仓库管理：列表和新增；出入库记录：业务联动流水和手工登记。                           |
| 采购 | 需求分析：选择计划、展开 BOM、计算库存缺料；请购单：自动生成、手工新增、详情、转采购；采购单：手工新增、详情、收货和采购记录。 |
| 生产 | 生产计划：新增、查询、查看 BOM、跳转分析、领料出库、完工入库。                                                                 |

使用通用后台布局、固定菜单与 hash 导航，可刷新、前进和后退。表格、表单和弹窗复用 Element Plus。

## 推荐演示流程

1. 在生产计划中查看“十月成型机交付计划”（5 台），或从两个预设产品中创建新计划。
2. 点击“分析缺料”，进入采购管理。初始 PLC、触摸屏、接触器、漏电开关分别缺 3、2、8、6 个。
3. 点击“生成请购单”，根据最新可用库存生成缺料明细。
4. 在请购单中点击“生成采购单”，填写采购人、供应商后确认。
5. 在采购单中点击“确认收货”，选择可用仓库整单收货，库存增加并生成采购入库流水。
6. 回到生产计划，点击“生产领料”，库存减少并生成各物料出库记录。
7. 点击“完工入库”，成品仓增加 5 台产品，并记录完工入库。
8. 在出入库记录中查看来源单号。刷新后数据保留，右上角“重置数据”恢复初始状态。

## 演示规则和边界

- 全部为 mock 数据，数量为正整数；固定 BOM 不代表真实产品配方。
- 只有参与可用量计算的仓库参与分析；现场仓和成品仓默认不参与。
- 缺料 = 需求 − 可分配库存 − 本计划待采购请购量 − 本计划在途采购量，最低为 0。
- 已生成请购的计划按首次请购先后占用物料，后续计划不重复使用已分配库存；这是演示约定。
- 请购转采购、采购收货、生产领料、完工均防止重复执行；在途采购不能直接用于生产领料。
- 整单转采购、整单收货、整单领料和完工；采购人及供应商必填，出库不允许负库存。
- 在数据副本中完成校验和修改，再一次性保存；保存失败明确提示，不发布部分更新。不支持跨标签页并发编辑。
- 单价仅用于参考金额，不涉及真实税额、付款或核算。
- 期初库存为 mock 快照，初始流水仅为示例；后续业务操作均生成流水。
- 审批、安全库存、损耗、替代料、排程、工序、委外和批次等未明确规则暂不实现，保留空态或说明。

## 代码结构

```text
src/demo/
  main.ts             # 无后端启动入口
  App.vue             # 布局、菜单和导航
  Inventory.vue       # 库存、仓库、出入库
  Procurement.vue     # 分析、请购、采购
  Production.vue      # 生产计划
  DocumentEditor.vue  # 通用单据明细录入
  model.ts            # mock 数据和业务操作
  store.ts            # 响应式状态和本地原子提交
  model.test.ts       # 演示闭环及边界测试
  style.css           # 页面和响应式样式
vite.demo.config.ts   # 无代理的开发、静态构建配置
 tsconfig.demo.json   # 仅检查演示代码
```

原模板的 `src/main.ts`、布局、接口、插件及视图源码保留，当前演示不加载它们。默认开发、构建与预览命令已切换到演示入口，原 `.env` 的后端及权限配置对当前演示无效。

数据保存在浏览器同源 localStorage（`wsn-erp-demo-v1`），不发送到外部服务。清除浏览器数据或更换域名/端口会获得独立的初始数据。
