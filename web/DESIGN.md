# WSN 前端设计约定

从同源 YSZN 后台延续的页面偏好。用于新页面和明确要求调整的页面，不要求批量改造现有页面；用户当次明确需求优先。

## 视觉与布局

- 面向中文后台操作人员，信息紧凑、层次清楚、操作位置稳定，复用 Vue 3、Element Plus 和现有主题。
- 当前实际入口是 `src/demo/main.ts`，主题真值是 `src/demo/style.css`：`--brand: #3167e3` 映射到 `--el-color-primary`，基础字号 14px、控件圆角 6px。沿用字体和语义变量，不强制覆盖为来源项目颜色。
- 标准列表按“筛选区 → 工具栏 → 表格 → 分页”组织，业务操作在工具栏左侧，显示设置在右侧。
- 筛选区默认展开，可以隐藏/显示；隐藏保留输入，不隐式清空或查询。提供查询、重置入口。
- 表格按需提供刷新、密度、全屏、列显隐/排序和外观设置；分页选项可沿用 10/20/50/100。
- 行内默认显示两个操作，其余收进“更多”；危险操作明确区分并确认。
- 图片浏览类业务可提供表格/卡片视图，用紧凑按钮组切换；ERP 普通列表不强制增加卡片。

## 表单与控件

- 使用 `ElForm/ElFormItem`。参考菜谱基本信息：标签在上方，相关字段双列排列，描述、图片等单独占行；窄屏改单列。
- 文本用 `ElInput`，描述用 textarea，枚举用 `ElSelect/ElOption`，多选项支持搜索，清空按业务需要启用。
- 数量、金额用 `ElInputNumber` 并明确范围和精度；少量互斥类型用 `ElRadioGroup/ElRadioButton`；布尔启停用 `ElSwitch`；日期使用 Element Plus 日期控件。
- 简单新增/编辑用 `ElDialog`，底部放取消和确认；复杂单据、档案保留现有独立详情，不强制塞入弹窗。
- 文件上传使用统一能力。原版 `FaFileUpload` 依赖后端，当前纯前端演示不能直接启用真实上传。

## 复杂流程参考

菜谱编辑器顶部放标题、版本、状态、保存/发布等操作；下方左侧约 20% 为主流程，右侧约 80% 为选中步骤详情，两侧独立滚动，窄屏上下排列。支持拖动排序和上下移按钮，右侧按步骤类型显示专用设置卡。基本信息、料盒说明、版本管理分开组织。

此布局仅适用于类似流程编排，不把 ERP 列表和普通单据统一改成 20%/80%。

## 公共组件与当前差距

当前演示初始化 Element Plus，标准列表使用 `src/demo/FaManagementList.vue`。该组件沿用来源的筛选与工具栏插槽结构，移除后台状态、权限和请求依赖。FaTableActions、FaFileUpload 的来源参考保留在 [设计参考目录](docs/design-reference/README.md)，尚未接入运行目录。

新增标准列表时优先评估接入 FaManagementList；行内操作复用 FaTableActions，上传使用统一组件。先核对状态管理、国际化、主题、自动导入和请求契约，再在 src 建立共享实现，避免逐页重复整套结构。树表、主从档案、流程画布可以使用专用结构并说明原因。

交互约定见 [UX-CONTRACT.md](UX-CONTRACT.md)，开发要求见 [AGENTS.md](AGENTS.md)。来源快照仅用于追溯，WSN 以本文件为准。

## 当前布局与组件映射

- 应用外壳由 `src/demo/App.vue` 维护：侧栏 212px，收起后 64px；顶栏 54px；取消重复的单页标签栏。主内容自然滚动，表格横向滚动由 Element Plus 自身容器承担。
- 标准列表由 `src/demo/FaManagementList.vue` 统一提供筛选显隐、查询/重置、行距、斑马纹、单元格边框和扩展模式。业务按钮在左侧，显示设置在右侧；扩展模式释放侧栏和页头占用，不创建模态层，Escape 或“退出扩展”恢复。
- 已接入库存、仓库、出入库、请购、采购、底稿、生产计划和物料列表。物料仍保留左分类、右列表；需求分析和档案详情沿用专用布局。
- `src/demo/style.css` 为运行时唯一主题真值：`--brand` → `--el-color-primary`；`--brand-soft` 用于选中背景；`--surface-filter` 用于筛选底色；`--radius-panel` 为 6px；`--space-page` 为 18px。滚动条使用 `--scrollbar-*` 全局变量，并提供高对比度系统回退。
- 字体沿用现有中文系统字体栈，业务正文 14px，页标题 22px；统计卡压缩留白，档案字段双列、窄屏单列。窄屏列表工具栏换行，不裁切整页内容。
- 当前为插槽列，未展示无法执行的列显隐/排序入口；来源组件的后台刷新和真实上传能力不在纯前端演示中启用。

## 首页工作台与导航

- `#home` 为默认首页，由 `src/demo/Dashboard.vue` 集中展示库存、生产、采购底稿、采购统计以及业务流程与入口，统计直接订阅 store，不单独维护副本。
- 标准业务页直接从筛选和工具栏开始，不再重复展示页面介绍、统计卡和流程概览。档案详情保留返回、编辑、保存操作与当前档案身份信息。
- 左侧导航支持整体收起及分组独立收起；进入收起分组所属页面时自动展开该组。窄屏整体收起会释放侧栏宽度。
- 需求分析归属生产管理，原 `#analysis` 链接保持兼容。

- 首页工作台为独立导航入口，不设置分组折叠按钮；其余业务分组保持可收起。
