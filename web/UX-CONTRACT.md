# WSN 页面交互约定

- 查询和重置回到第 1 页；筛选区显隐保留输入；按业务保留分页与筛选上下文，不无故增加 URL 状态系统。
- 查询、保存显示 loading；保存中防重复提交；失败明确提示并保留输入，不吞异常、伪成功或以默认数据掩盖失败。
- 选择器显示中文业务名称，选项加载失败提供提示和重试；上游字段切换时清理不兼容的下游选择。
- 表单行内显示校验错误；删除和不可逆业务操作用 Element Plus 确认框；离开有未保存修改的编辑器时确认。
- 图标按钮具备中文操作名称、键盘激活及可见焦点；禁用或加载中不能触发，不意外提交所在表单。
- 弹窗适应视口；表格横向滚动保留在表格容器内；窄屏减少表单列数，不以全局隐藏溢出掩盖内容。
- 合适业务的列表/卡片切换保留查询上下文；加载、空态、错误明确区分。
- 继续遵循 README 的纯前端 mock、本地原子保存和防重复业务操作约定，不迁入来源项目的登录、VIP、授权或菜谱发布权限。
- 本约定用于后续开发和明确要求调整的页面，不表示全部既有页面已实现或验收。

- 首页为 `#home`，空 hash 或无效入口回到工作台。概览卡片和流程入口跳转到现有业务页面，不修改业务状态。
- 导航分组使用按钮声明展开状态，键盘可激活；整体收起与分组收起独立控制。导航改变时展开当前页面所在组。

- 所有实际 hash 页面变化（含详情、浏览器前进后退）统一展示 300ms loading，连续跳转重新计时；点击当前页面不额外触发 loading，组件卸载清理计时器。

## 页面缓存与返回

- 业务页面采用 KeepAlive，按完整路由独立缓存；切换后保留筛选、分页、勾选、表单和详情，恢复文档滚动位置。
- 来源单据跳转在页面激活时处理，避免仅首次挂载消费参数导致缓存页打开旧单据。
- 缓存页面通过共享 CachedDialog/CachedDrawer 接入 Element Plus 弹层，离页隐藏并释放遮罩、滚动锁；隐藏不等于取消，不丢弃表单或详情。
- 缓存仅在当前应用会话内存在；刷新重新建立，重置演示数据同时清空页面缓存。


## 本轮业务审核与执行交互

依据：[已确认 TODO](../todo/TODO.md)。

- 计划、底稿按未审核/已审核分组；审核状态与业务执行状态分别显示，未审核才可编辑，已审核才可进行对应下游业务。
- 返审失败明确展示已审核直接下游的原因；不可仅按下游存在性禁用。删除与取消编辑不破坏已保存引用和业务数据。
- 采购审核前列出来源数量差异（物料、来源单号、要求量、本次数量），取消不修改审核状态，确认后继续完整校验与提交。
- 采购编辑支持逐行取料、移除任意来源行、修改数量/含税单价/交期/备注；取消保留原已保存明细。来源不显示虚构剩余量，不按已取料禁选。
- 采购页面不提供收货操作或“收货管理”入口；独立收货页区分待收货、实收确认和已收货，建立占用时不提示入库成功。
- 领料单明示实际仓库库存，可移除、多次部分领料；不展示或校验虚构的 BOM 剩余未领量。
- 计划详情以 100/200/500 分页结合虚拟滚动展示明细，切页、每页条数或计划变化时重新定位有效页与滚动位置，保留数据文字选中复制能力。
