# Web 开发约定

- 前端开发前阅读 [README.md](README.md)、[DESIGN.md](DESIGN.md) 和 [UX-CONTRACT.md](UX-CONTRACT.md)，用户当前明确需求优先。
- 当前入口是 src/demo；先追踪真实入口和 import，不把原模板保留的组件当作演示已启用的能力。
- 新页面和明确要求修改的页面遵循设计约定，不顺手批量重构，不改变 ERP 业务算法和本地保存规则。
- 标准列表优先接入并复用 FaManagementList；操作列复用 FaTableActions；上传复用统一能力。先阅读 [参考说明](docs/design-reference/README.md)，核对依赖后再接入，不把源码快照直接当作可运行组件包。
- 表单使用 Element Plus，继承统一主题；筛选区可隐藏且保留条件；复杂流程可参考左流程、右详情布局。
- 文档和必要代码注释使用中文，参考使用仓库内相对路径，不依赖开发者本机另一个项目目录。
- 文档改动检查链接及格式；代码改动先做针对性验证，再按风险运行 pnpm type-check、pnpm test:demo、pnpm build。

## 已确认的 UI 偏好

- 采用紧凑、层次清楚的中文后台布局，沿用现有蓝色主题和 Element Plus；减少重复标题、装饰性说明和过大留白。
- 各业务页表格上方的页面介绍、统计卡、流程概览统一集中到首页工作台，业务列表直接从筛选区、工具栏开始。保留必要的筛选条件、业务操作及当前单据或档案身份信息，不将这些操作移到首页。
- 首页工作台为默认首页（`#home`），集中展示库存、生产、采购底稿与采购概览、业务流程和快捷入口；统计复用现有业务状态，不维护独立数据副本。
- 首页工作台在左侧导航中直接显示，不设置额外的“工作空间”折叠组。侧栏支持整体收起，库存、采购、生产等业务分组支持独立展开和收起；跳转后展开当前页面所在分组。
- “需求分析”作为生产计划内的弹窗组件，由“分析缺料”打开，不再设独立导航菜单；旧链接兼容转到生产计划。
- 所有实际页面跳转统一显示全局半透明遮罩、转圈及“正在加载…”提示，持续 **0.3 秒（300ms）**，包括菜单、工作台入口、详情页和浏览器前进后退。连续跳转以最后一次重新计时，点击当前页面不重复触发；遮罩不占布局空间，沿用不拦截点击的行为，卸载时清理计时器。
- 列表统一采用“筛选区 → 工具栏 → 表格 → 分页”；筛选区可收起且保留条件与结果。业务按钮在左，显示设置在右，复用共享列表能力，避免逐页重复实现。
- 档案表单默认双列、窄屏单列；表格横向滚动留在表格容器中，详情表单保持自然滚动，不通过裁切整页内容来适配窄屏。

- 名称、品号、单号等业务数据入口统一复用 `src/demo/DataLink.vue`，支持文字选中复制，拖选不触发跳转；页面导航使用链接，打开抽屉使用可选中文字的按钮。保存、删除等操作按钮保留原有语义。
