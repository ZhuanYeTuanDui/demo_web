# 库存功能总结

## 材料范围

本总结依据本目录 `1.png`～`4.png`，用于后续 Web ERP 需求梳理。截图能够确认页面、字段和示例数据，不能据此认定后台计算、保存和过账行为已得到验证。

## 一句话概括

库存模块不仅记录“有多少货”，还维护商品和仓库资料，区分不同仓库中的库存、借出数量、成本以及真正参与需求计算的可用量。

## 截图与现有功能

| 来源 | 页面 | 可确认的功能 |
| --- | --- | --- |
| [1.png](1.png) | 库存汇总表 | 按商品展示分类、品号、品名、规格、库存单位、数量、成本和会计分类；报表显示截止日期及仓库性质范围。 |

## 核心信息

### 商品资料

- 标识与分类：品号、品名、规格、快捷码、商品分类、会计分类、品牌、材质。
- 单位与存放：库存单位、采购单位、销售单位、主要仓库、存放位置。
- 采购与生产属性：主要来源、主供应商、是否指定主供应商、工艺路线编号、指定 BOM。
- 库存与补货属性：前置天数、安全存量、最低补量、补货倍量、按需求补货、批号管理、失效状态。
- 核算属性：成本计价方式、税率、人工分摊权数、制造分摊权数、领料倍量、存货核算开关。
- 页面另有“单价”“选配属性”“照片/描述”“数据浏览”页签，内部内容未展示。

截图中的成本计价方式示例为“月加权平均”，不代表系统仅支持这一种方式。

### 仓库资料

截图展示存货仓、现场仓、委外仓等性质，以及钣金仓库、不良仓库、半品仓库、标准件仓库、成品仓库、呆料仓库、辅材仓库、机加仓库等具体仓库。

“纳入可用量计算”是独立配置：部分仓库虽有实物库存，但不参与可用量计算。商品的主要仓库和仓库是否参与可用量计算属于不同概念。

### 库存查询口径

商品查询中心同时展示现有库存量、现有库存成本、借出量、实际在库量，并可下钻到各仓库。下方库存供需区域可见库存可用量、预计进货和预计销货。

例如 `3.png` 中同一商品总库存为 365，其中标准件仓库 66、现场仓 299；现场仓不纳入可用量计算，界面显示库存可用量为 66。这说明不能直接把所有仓库数量之和当成可用库存。

截图还出现个别仓库成本为负、数量为零但成本不为零的情况。这些是可见数据现象，不能直接断言是系统缺陷；需要结合计价和结账规则解释。

## 与其他业务的关联

1. 商品资料为采购、BOM、生产领料和入库提供统一品号、单位及分类。
2. 仓库是否参与可用量计算，会影响物料需求计算时的缺料判断。
3. 采购收货、生产领退料、生产入库等业务应与库存台账关联；本目录未展示这些单据的实际过账过程。
4. 成本字段与库存核算相关，但成本更新时点和计算过程未展示。

## Web ERP 功能划分建议

| 建议入口 | 包含内容 |
| --- | --- |
| 基础资料 → 商品 | 商品分类、商品档案、单位、主要来源、默认仓库、供应商及补货属性。 |
| 基础资料 → 仓库 | 仓库性质、可用量参与规则、启停状态。 |
| 库存管理 → 库存查询 | 总库存、分仓库存、借出量、实际在库量、可用量和成本，合并为一个查询入口。 |
| 库存管理 → 供需查询 | 当前可用量、预计收发及关联业务单据；具体计算规则确认后实现。 |
| 配置中心 | 单位、类型等字典统一维护；计价和可用量规则保留业务校验，不做无约束的通用字段。 |

## 待确认事项

- 现有库存量、实际在库量、借出量和可用量各自的精确定义；是否存在占用、冻结或预留库存。
- 预计进货、预计销货分别统计哪些单据、哪些状态，如何避免重复计入。
- 是否允许负库存；负成本、零数量有成本的业务原因和处理方式。
- 仓库是否需要库位层级；批号、条码及多单位换算的具体规则。
- 采购及生产单据在保存、审核还是其他时点更新库存，撤销时如何回退。

以上事项是后续规则确认点，不作为截图已经证明的现有功能。
