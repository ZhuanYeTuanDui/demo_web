# Excel 生产计划导入

## 操作路径

1. 打开“生产管理 → 生产计划”，点击“导入 Excel”，在上传区域点击选择或拖入 `.xls`、`.xlsx` 文件。选中后显示文件名，可再次点击或拖入文件进行替换。
2. 核对解析出的工作表、物料名称、图号/规格、数量、单位和关联物料。
3. 为每张表填写计划名称、计划数量，选择表内数量含义，并填写计划日期。
4. 源表没有单位时，优先沿用唯一匹配物料的库存单位，其余默认补“个”；空白数量默认补 1。预览中可逐行修改单位和数量，补入缺省值的明细数量会显示提示。
5. 点击“生成生产计划”，每张匹配的工作表生成一个独立计划。
6. 在计划列表点击“分析缺料”，继续“生成采购底稿 → 转采购单 → 收货入库 → 生产领料 → 完工入库”。

## 工作表匹配

- 只有一个非空工作表时，不限制表名，直接解析该表；其余全空模板页不生成计划。
- 有多个非空工作表时，仅匹配名称为“机加、标准、钣金、电气”的工作表，允许表名前后空格。
- “新增机加”“机加备份”等名称不匹配；忽略的工作表在预览中列出。
- 没有匹配工作表、缺少必要表头或明细校验失败时，不允许生成计划。

## 支持的表头和版式

支持表头前的标题与单据信息，以及明细中穿插的部件分组合并行。读取以下字段：

| 字段 | 支持的表头 |
| --- | --- |
| 名称（必需） | 名称、品名、物料名称 |
| 数量（缺省为 1） | 数量/台、数量、单台用量、用量；整列缺失也默认补 1 |
| 型号规格 | 型号/规格、规格/型号、规格、型号 |
| 图号 | 图号、图纸编号 |
| 单位 | 单位、库存单位 |
| 品牌、材质、表面处理、备注 | 同名字段 |
| 重量 | 重量（Kg）、重量、单重（Kg）等；忽略表头括号与空白 |
| 原表序号 | 序号；仅用于识别预留空行，不作为物料主键 |

数量须为正整数；只有未填写时补 1，零、负数、小数和无效文字仍报错。空行、仅序号的预留行、重复表头、“以下空白”不计入物料；名称缺失等错误明确报错，不静默丢弃。

数量、重量中的公式须先转换为数值，避免使用旧缓存。图片备注仅保留未导入提示，不导入图片本体。单个文件最大 10 MB，单表最多 10000 行、200 列。

## 数量口径

- 表头为“数量/台”“单台用量”时，默认每台用量，需求量 = 表内用量 × 计划数量。
- 表头为“数量”“用量”时，默认本次总需求，计划数量固定为 1；可在核对后切换为每台用量。
- 同一计划中的同一物料合并用量后参与库存、采购与领料计算；原始行号、部件及用量另外保留在计划来源信息中。
- 每个物料的最终需求量上限为 100000，与现有采购、收货及出入库数量规则保持一致。

## 物料关联与保存

- 加工件按图号、名称及加工属性匹配；其他物料按名称、规格、品牌及单位匹配。不会仅凭同名使用已有库存。
- 唯一匹配的物料自动关联；多个匹配时必须选择关联档案，或明确作为新物料建档。
- 未匹配的物料自动建档，不覆盖已存在的物料资料；已有物料缺单位时可用本次核对的单位补齐。
- 缺规格且无图号的物料无法可靠自动匹配，会创建独立档案。名称仍为必填；数量缺省为 1。品牌、材质等未知业务属性保持空白，不虚构取值。
- 无单价信息的新物料参考价为 0，并标注来源未提供价格；不代表实际采购价格为零。
- 每张表创建独立的计划产出物料和 BOM 快照，不改写原有示例产品 BOM。所有工作表校验成功后统一保存，任意一张表失败都不留下部分计划或档案。
- 数据继续保存在当前浏览器；刷新后保留。再次确认导入会创建新计划，适用于新增生产批次，不会覆盖已有计划。
