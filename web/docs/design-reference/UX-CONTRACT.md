# 后台业务交互约定

本约定记录本次 VIP 与菜谱功能复用的现有交互，不要求批量改造其他页面。

| 能力 | 公共实现 | 当前流程 |
|---|---|---|
| 列表与选择 | FaManagementList | 服务端分页，筛选回到首页，仅变更显式选中的设备 |
| 行内操作 | FaTableActions | 编辑、指定设备、删除沿用统一按钮和更多菜单 |
| 选择器 | Element Plus ElSelect | 中文标签，失败不伪造选项，未选中时行内校验 |
| 表单 | ElForm / ElFormItem | 保存中阻止重复请求，失败保留输入 |
| 弹窗 | ElDialog / ElMessageBox | 原生键盘与焦点管理；设备换绑、解绑先确认 |
| 反馈 | ElMessage / ElAlert | 成功由响应确认；设备请求失败提供可见错误和刷新入口 |
| 样式与滚动 | 现有 styles 及公共列表 | 继承主题，不增加全局布局限制 |

VIP 新增保存后打开指定设备弹窗，可关闭后再绑定；编辑保存返回原列表页。
设备绑定仅影响所选 ID，换绑更新原关系；解除后设备不再有菜谱访问权。
菜谱基本信息编辑沿用草稿保存流程，已发布内容保持只读。
等级属于菜谱基本信息，修改影响其所有版本；版本列表不能用于绕过等级校验。

列表查询保留现有页面内状态，不新增 URL 状态系统。设备搜索响应采用请求序号，
过期响应不能覆盖新结果。加载与保存使用现有 loading 反馈，错误不当作空数据。

注册码页右上角复用菜谱管理的 ElButtonGroup 切换样式，在“注册码 / 授权记录”两个列表间切换。
两侧保留各自筛选、分页和列表状态，授权记录首次切换时加载；失败显示错误并允许查询或刷新重试。
离线授权工具栏按钮直接打开签发表单；签发、设备建档和详情复用 ElDialog，不另设授权记录弹窗。

认证请求遇到 401 最多续期重放一次，同一会话的并发请求共用续期结果；公开请求不续期。
登出立即结束本地会话，旧请求或迟到续期不能写回令牌、清理新账号或跳转新账号页面。
正常令牌续期保持同一会话，列表缓存与在途结果不会因此被误当作切换账号。

菜谱导出先输入名称再创建后台任务；弹窗显示生成、合并和上传进度，关闭弹窗不取消任务。
导出记录只展示本人任务，显示导出人、总数、成功/跳过数、完成与过期时间；完成后由用户主动下载，7 天内可重复下载，过期后不可下载。

共享图标按钮使用原生 `button` 和明确的中文操作名称，支持键盘激活与可见焦点；
默认 `type="button"`，禁用或加载中不能触发操作，也不能提交所在表单。

首页、仪表盘、大屏和运营分析的数据来源由后端启动配置统一控制，默认示例数据；页面不提供来源切换或示例横幅。
筛选和数据来源传给后端统一计算；缺失金额、成本或能耗显示“暂无数据”，无对比基数显示“暂无对比”。
查询失败显示可恢复错误，不能回退前端模拟数据；过期响应不覆盖新结果，正式与示例结果不混算。
这些统计页沿用页面内筛选状态与 Element Plus 选择器、日期控件、loading、ElAlert/ElEmpty，不改造全局主题。

微信订单沿用 FaManagementList 新增入口与 ElDialog 表单，新增商品为客户名下设备，支持租赁和永久购买。
租赁选择已配置周期，金额由服务端读取对应租价；永久购买由下单人员填写正金额，最多两位小数。切换客户清空设备，切换设备或交易类型清空不兼容的周期和金额；无租价时明确提示并禁止提交租赁订单。
创建为待支付，不授予 VIP、不自动改设备归属或租期；历史会员订单保留查询，订单页不再提供会员分配入口。
保存失败保留表单，选项失败禁止提交；页面隐藏顶部四张统计卡，不再提供仅写浏览器内存的假状态修改/删除。
