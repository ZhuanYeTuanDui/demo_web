# 页面字段调整清单（待实施）

本轮未修改 Vue 页面。下列清单用于下一轮确认和开发；按原文 37 个条目组织，覆盖 682 项字段/控件。不同页面重复出现的同一字段只保留一个数据真值。

配套：[数据库设计](README.md)、[字段字典](字段字典.md)、[原始字段及规则](source-fields.json)。文档中的“建议”、取消项、延期项与现有流程冲突均单独处理，不把所有控件当成数据库列。

## 实施顺序

1. 先补纯信息字段：仓库联系人、单据部门/备注、工单起止日期、发货地址与联系人；完成新增、编辑、详情和本地保存的闭环。
2. 再补查询展示：库存矩阵、来源追踪、行数汇总和到料概览；未知成本/审核身份不补假值。
3. 最后独立实施业务能力：请购/发货审核、需求行结束、四公式分析、税额计算、打印模板及日志；每项都须同时改模型、保存和测试。

## 原文字段逐页核对

标记说明：**保留/对齐**不代表当前已完整实现；它表示后续逐项检查展示与保存。**计算后展示**不能直接新增可编辑输入框。**界面状态**不进入业务表；如需持久化打印设置则保存到模板配置。
