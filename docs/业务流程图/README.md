## 共用保存规则

所有业务先在数据副本中校验与修改，再一次性写入浏览器 localStorage，成功后更新页面；失败提示错误，不发布部分修改。数据不跨浏览器或设备共享。

## 关键边界

- 工单立项中、采购中、装配中、待出货由人工切换；已发货由发货操作触发。
- 缺料分析保留建议计算；领料只看所选正常仓库实际库存，不受分析占用或采购单限制。
- 收货先建待收货单预占，再实收确认入库，支持分批与差额释放。领料可移除物料、多次部分办理，不累计限制 BOM 余量。完工不依赖领料记录，仍禁止重复完工；成品发货保留整工单边界。
- 当前闭环截止库存与单据状态，不包含付款、开票、物流签收、退货、成本结转。
- 档案维护属于独立操作闭环，未将查询、筛选、打印单独扩展成业务闭环。

- 计划、底稿和采购的审核与执行状态独立；反审核统一检查已审核的直接下游，没有或全部未审核时允许。
- 底稿只由采购页取料，已审核底稿才可选；底稿、请购来源要求量不变，可重复取用，审核数量有差异时提示确认继续。
- 采购金额按数量 × 含税单价计算，交期与备注逐行保存。
